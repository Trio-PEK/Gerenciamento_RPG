# Gerenciador de Aventura de RPG

Projeto de console em Java (JDK 25) para a Atividade III.

## Conceitos obrigatórios destacados no código

- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Interface
- Validação antes da instanciação
- Tratamento de exceções

Os comentários no código usam marcações como `POO — ENCAPSULAMENTO`, `POO — HERANÇA`,
`POO — POLIMORFISMO`, `POO — ABSTRAÇÃO`, `POO — INTERFACE` e
`REQUISITO — VALIDAÇÃO` para facilitar o estudo e a apresentação.
